# مدرستي (school_lite)

تطبيق تعليمي عربي سريع وعالي الأداء، **بديل لمطبيـق Moodle** — يبني واجهات
ناتيف بالكامل (بدون WebView) ويعمل **Offline-First** ليعمل حتى عند انقطاع
الإنترنت. مبني بـ Flutter لنظامي Android و iOS.

> الحالة الحالية: **الخطوتان 1 و 2** من خطة التنفيذ (الهيكل والحسابات
> والقفل + قاعدة Drift/SQLite ومحرك المزامنة وطابور التسليم دون إنترنت).

## خطوات التشغيل

```bash
# 1) تنزيل الحزم
flutter pub get

# 2) توليد كود قاعدة البيانات (إلزامي — ملف app_database.g.dart)
dart run build_runner build --delete-conflicting-outputs

# 3) فحص الكود (إلزامي قبل التسليم)
flutter analyze

# 4) تشغيل الاختبارات (RTL + الشاشات + الحسابات + القفل + القاعدة + المزامنة)
flutter test

# 5) توليد مجلدات المنصات إن لم تكن موجودة بعد
flutter create --project-name school_lite --platforms=android,ios .

# 6) تشغيل التطبيق
flutter run
```

> ملاحظة Windows: اختبارات القاعدة تحتاج `sqlite3.dll` في مسار البحث؛
> إن لم تتوفر تُتخطّى تلك الاختبارات تلقائياً (بقية الاختبارات تعمل).

## أول استخدام

1. يفتح التطبيق مباشرة بواجهة عربية RTL.
2. اختر **«الوضع التجريبي»** لاستكشاف التطبيق ببيانات فورية، أو أدخل
   **رابط خادم Moodle** + اسم مستخدم + كلمة مرور (يتم الحصول على التوكن
   عبر `login/token.php` مباشرة — بدون أي WebView).
3. من **الإعدادات ← قفل برمز PIN** يمكنك تفعيل القفل (4–6 أرقام، محفوظ
   مُجزَّأ SHA-256 + ملح محلياً) مع فتح بالبصمة إن كان الجهاز يدعمها.
4. **شريط الحسابات العلوي**: ضغطة واحدة للتبديل بين حتى 10 حسابات طلاب
   — بضغطة مطوّلة يُفتح إدارة الحسابات، وزر «+» لإضافة حساب جديد.

---

## ربط خادم Moodle الخاص بك

- من **الإعدادات** (أو شاشة الدخول) غيّر الرابط، ويُفضّل خدمة الويب
  `moodle_mobile_app` مفعّلة على الخادم (`Site administration → Mobile app`).
- التوكن يُحفظ في Keystore/Keychain عبر `flutter_secure_storage` ولا
  يُكتب أبداً في قاعدة البيانات أو الملفات العادية.
- الوضع التجريبي يعمل دون إنترنت تماماً ويُميَّز بشارة «الوضع التجريبي».

## المزامنة وقاعدة البيانات (الخطوة 2)

- **قاعدة واحدة** (`school_lite_v1.db` عبر Drift/SQLite) بثمانية جداول، وكل
  صف محتوى يحمل `accountId` ومعرّف مركّب `accountId:moodleId` لعزل تام
  حتى لو تساوى رقم Moodle بين طالبين. بيانات «الحسابات» نفسها تبقى في
  SharedPreferences لضمان إقلاع sync خالٍ من المخاطر.
- **Offline-First**: الواجهات تشاهد Streams من القاعدة فتعرض المحفوظ فوراً؛
  المزامنة تجري في الخلفية (يدوياً بالزر، تلقائياً عند عودة الإنترنت،
  ودرياً كل ~30 دقيقة عبر workmanager).
- **طابور التسليمات**: حفظ أي إجابة (نص/ملفات) = معاملة ذرّية واحدة
  (واجب `queued` + مدخل طابور)، ثم يُرفع عند توفر الشبكة — أخطاء الشبكة
  تعيد الجدولة فوراً، وأخطاء الخادم بـ backoff أسّي (≤ ساعة)، ولا تُكتب
  إجابة فوق حالة معلّقة مهما جلبت المزامنة التالية.
- **مصراان للمحتوى**: `MoodleContentSource` (كل wsfunction + upload.php
  لرفع المرفقات) و`DemoContentSource` الوضع التجريبي — نفس العقد، فيعمل
  كل شيء (مزامنة، طابور، إشعارات) بلا إنترنت.

## ملاحظات الأداء

- الإقلاع البارد < ثانية: تهيئة خفيفة فقط قبل أول إطار، وتأجيل كل العمل الثقيل.
- تبديل الحسابات: استعلام محلي بحت (بلا شبكة) — حالة الشاشة محفوظة بـ `IndexedStack`.
- لا يوجد WebView في التطبيق إطلاقاً — حتى وصف HTML يُحوَّل لودجتات ناتيف.
