# مدرستي (school_lite)

تطبيق تعليمي عربي سريع وعالي الأداء، **بديل لمطبيـق Moodle** — يبني واجهات
ناتيف بالكامل (بدون WebView) ويعمل **Offline-First** ليعمل حتى عند انقطاع
الإنترنت. مبني بـ Flutter لنظامي Android و iOS.

> **الإصدار المستقر v1.1.0**: الخطوات 1–3 مكتملة (الهيكل والحسابات والقفل +
> قاعدة Drift/SQLite ومحرك المزامنة + **ربط كامل مع خادم Moodle** بجميع
> الشاشات). جاهز للإنتاج: **`flutter analyze` نظيف وكل الاختبارات إلزامية**،
> وملف APK متاح للتحميل في [Releases](https://github.com/aslaifuddin-beep/school-lite/releases/latest).

---

## الميزات الرئيسية

- **واجهة عربية RTL بالكامل** — نصوص وتنسيق عربي في كل الشاشات، بدون WebView إطلاقاً.
- **Offline-First** — كل الشاشات تشاهد Streams من قاعدة Drift/SQLite محلياً وتعرض المحفوظ فوراً حتى دون إنترنت.
- **دعم Moodle API أصلي** — تسجيل دخول عبر `login/token.php` مباشرة، جلب المقررات والواجبات والإشعارات، ورفع المرفقات عبر `upload.php`.
- **اكتشاف مجلد Moodle تلقائياً** — يتابع روابط 301/302 فيفتح خوادم `moodle.unrwa.org/moodle` ونحوها دون إعداد يدوي، مع تجاوز شهادات ذاتية التوقيع ورسائل أدق للخطأ (SSL ≠ انقطاع شبكة ≠ خطأ خادم).
- **شاشات مربوطة بالكامل** — الرئيسية (واجبات + دروس اليوم + إشعارات)، المقررات وأقسامها، الواجبات بفلاتر استعجالية، والإشعارات بتحديث «الكل كمقروء» — كلها من قاعدة البيانات مباشرة.
- **مهام اليوم والتسليم بلمسة** — بطاقة «مهام اليوم» (المتأخرة والمستحقة خلال 24 ساعة) مع تسليم سريع بالكاميرا مباشرة إلى طابور المزامنة.
- **قارئ PDF داخلي وتنزيل للمواد** — عرض ملفات PDF داخل التطبيق (PdfRenderer بلا WebView) وتنزيل مواد المقرر للعمل دون إنترنت مع شارات «محفوظ محلياً».
- **تبديل الحسابات** — حتى 10 حسابات طلاب بضغطة واحدة من الشريط العلوي، مع إدارة الحسابات بضغطة مطوّلة.
- **قفل PIN/البصمة** — رمز 4–6 أرقام محفوظ مُجزَّأ SHA-256 + ملح، مع فتح بالبصمة إن كان الجهاز يدعمها.
- **مزامنة خلفية** — يدوياً بالزر، تلقائياً عند عودة الإنترنت، ودرياً كل ~30 دقيقة عبر workmanager.
- **طابور تسليم دون إنترنت** — أي إجابة (نص/ملفات) تُحفظ ذرّياً وتُرفع لحظة عودة الشبكة، مع إعادة جدولة ذكية للأخطاء.
- **وضع تجريبي كامل** — استكشاف التطبيق ببيانات فورية بدون خادم.

## التنزيل والبناء عبر GitHub Actions

- **تنزيل APK جاهز**: [الإصدارات الرسمية (Releases)](https://github.com/aslaifuddin-beep/school-lite/releases/latest) — أحدث إصدار مع حزمة APK مرفقة.
- **بناء تلقائي**: كل دفع إلى فرع `main` يشغّل [.github/workflows/build_apk.yml](.github/workflows/build_apk.yml) ويمرّ بخطواته:
  1. توليد كود قاعدة البيانات (`dart run build_runner build`) والتحقق من الملف المولَّد.
  2. `flutter analyze` — **إلزامي** (0 ملاحظات توقف البناء).
  3. `flutter test` — **إلزامي** (كل الاختبارات: RTL، الشاشات، الحسابات، القفل، القاعدة، المزامنة، الشبكة، عزل الحسابات، ربط الواجهات).
  4. `flutter build apk --release --no-tree-shake-icons` — **Fat APK** واحد يشمل `arm64-v8a` و `armeabi-v7a` (Java 17، minSdk 21، core library desugaring).
  5. توقيع ثابت عبر `debug.keystore` محفوظ بـ `actions/cache` (كل عمليات البناء توقّع بنفس المفتاح → التثبيت المتتالي بلا رفض التوقيع).
  6. رفع نتيجة البناء كـ Artifact باسم `school-lite-apk`.
- **للتحميل من Actions**: صفحة [Actions](https://github.com/aslaifuddin-beep/school-lite/actions) ← آخر Run ناجح ← في الأسفل **Artifacts** ← حمّل `school-lite-apk`.

## خطوات التشغيل

```bash
# 1) تنزيل الحزم
flutter pub get

# 2) توليد كود قاعدة البيانات (إلزامي — ملف app_database.g.dart)
dart run build_runner build --delete-conflicting-outputs

# 3) فحص الكود (إلزامي قبل التسليم)
flutter analyze

# 4) تشغيل الاختبارات (RTL + الشاشات + الحسابات + القفل + القاعدة + المزامنة)
flutter test

# 5) توليد مجلدات المنصات إن لم تكن موجودة بعد
flutter create --project-name school_lite --platforms=android,ios .

# 6) تشغيل التطبيق
flutter run
```

> ملاحظة Windows: اختبارات القاعدة تحتاج `sqlite3.dll` في مسار البحث؛
> إن لم تتوفر تُتخطّى تلك الاختبارات تلقائياً (بقية الاختبارات تعمل).

## أول استخدام

1. يفتح التطبيق مباشرة بواجهة عربية RTL.
2. اختر **«الوضع التجريبي»** لاستكشاف التطبيق ببيانات فورية، أو أدخل
   **رابط خادم Moodle** + اسم مستخدم + كلمة مرور (يتم الحصول على التوكن
   عبر `login/token.php` مباشرة — بدون أي WebView). الافتراضي
   `https://moodle.unrwa.org`، والتطبيق **يكتشف مجلد Moodle تلقائياً**
   (مثل `/moodle`) عبر متابعة توجيهات الرابط.
3. من **الإعدادات ← قفل برمز PIN** يمكنك تفعيل القفل (4–6 أرقام، محفوظ
   مُجزَّأ SHA-256 + ملح محلياً) مع فتح بالبصمة إن كان الجهاز يدعمها.
4. **شريط الحسابات العلوي**: ضغطة واحدة للتبديل بين حتى 10 حسابات طلاب
   — بضغطة مطوّلة يُفتح إدارة الحسابات، وزر «+» لإضافة حساب جديد.

---

## ربط خادم Moodle الخاص بك

- من **الإعدادات** (أو شاشة الدخول) غيّر الرابط، ويُفضّل خدمة الويب
  `moodle_mobile_app` مفعّلة على الخادم (`Site administration → Mobile app`).
- التوكن يُحفظ في Keystore/Keychain عبر `flutter_secure_storage` ولا
  يُكتب أبداً في قاعدة البيانات أو الملفات العادية.
- الوضع التجريبي يعمل دون إنترنت تماماً ويُميَّز بشارة «الوضع التجريبي».

## المزامنة وقاعدة البيانات (الخطوة 2)

- **قاعدة واحدة** (`school_lite_v1.db` عبر Drift/SQLite) بثمانية جداول، وكل
  صف محتوى يحمل `accountId` ومعرّف مركّب `accountId:moodleId` لعزل تام
  حتى لو تساوى رقم Moodle بين طالبين. بيانات «الحسابات» نفسها تبقى في
  SharedPreferences لضمان إقلاع sync خالٍ من المخاطر.
- **Offline-First**: الواجهات تشاهد Streams من القاعدة فتعرض المحفوظ فوراً؛
  المزامنة تجري في الخلفية (يدوياً بالزر، تلقائياً عند عودة الإنترنت،
  ودرياً كل ~30 دقيقة عبر workmanager).
- **طابور التسليمات**: حفظ أي إجابة (نص/ملفات) = معاملة ذرّية واحدة
  (واجب `queued` + مدخل طابور)، ثم يُرفع عند توفر الشبكة — أخطاء الشبكة
  تعيد الجدولة فوراً، وأخطاء الخادم بـ backoff أسّي (≤ ساعة)، ولا تُكتب
  إجابة فوق حالة معلّقة مهما جلبت المزامنة التالية.
- **مصراان للمحتوى**: `MoodleContentSource` (كل wsfunction + upload.php
  لرفع المرفقات) و`DemoContentSource` الوضع التجريبي — نفس العقد، فيعمل
  كل شيء (مزامنة، طابور، إشعارات) بلا إنترنت.

## ملاحظات الأداء

- الإقلاع البارد < ثانية: تهيئة خفيفة فقط قبل أول إطار، وتأجيل كل العمل الثقيل.
- تبديل الحسابات: استعلام محلي بحت (بلا شبكة) — حالة الشاشة محفوظة بـ `IndexedStack`.
- لا يوجد WebView في التطبيق إطلاقاً — حتى وصف HTML يُحوَّل لودجتات ناتيف.
